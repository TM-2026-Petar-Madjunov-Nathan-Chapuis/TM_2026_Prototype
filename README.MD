# TM_2026_Prototype

Prototype de jeu de survie en 3D développé avec Unity dans le cadre d'un travail de maturité

## Documents annexes
Cette repository comporte les deux annexes externes au rapport de TM en pdf : 
- La **transcription** de l'interview avec DNA Studios
- Le **GAME DESIGN DOCUMENT** de notre jeu, imaginé au début du projet

## Résumé du jeu

- Explorer un environnement enneigé.
- Surveiller sa santé, sa faim, sa soif et sa température.
- Ramasser et utiliser des objets.
- Gérer son inventaire.
- Présence d'une créature, un renard
- Sauvegarde de la progression.
- Récolter du bois pour se réchauffer à l'aide d'un camp de feu
- Cuire sa viande à l'aide du même camp de feu

Le projet est encore en développement. Certaines fonctionnalités peuvent être ajoutée d'ici la soutenance orale.

## Jouer
### Installation
Pour l'instant, seul windows possède un build, car la neige n'est disponible que sur windows et non sur mac.

Pour jouer, il faut télécharger puis extraire le fichier disponible dans les **[Releases](../../releases)** du projet.

Il suffit ensuite de lancer le fichier .exe

### Touches
- <kbd>W</kbd><kbd>A</kbd>S<kbd></kbd><kbd>D</kbd> - Touches de déplacements
- <kbd>I</kbd> - Ouvrir l'inventaire
- <kbd>T</kbd> - Toggle entre caméra première personne et caméra troisième personne
- <kbd>E</kbd> - Intéragir

## Développement

Le projet peut être ouvert avec **Unity** à partir du dépôt. Il suffit d'importer le dossier en tant que projet unity.
